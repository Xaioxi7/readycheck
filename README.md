# ReadyCheck prototype (TMC 498, Honeywell)

Pre-duty alertness check for pilots: the standard 3-minute PVT-B reaction test, plus eyelid analysis through the phone camera (MediaPipe), plain-language results, a readiness logbook, wearable wings badges, and a confidential support entry point.

## Open it
- On this computer: double-click `index.html`. The camera only works when the page is served over https, so locally use "Skip the camera" or Me > Demo mode.

## Share a link with friends (GitHub Pages)
1. github.com/new, name it `readycheck`, Public, Create repository.
2. Click "uploading an existing file", drag in `index.html`, Commit changes.
3. Settings > Pages > Branch: main, / (root) > Save.
4. After 1 to 2 minutes the link is https://xaioxi7.github.io/readycheck/

Each person's results stay in their own browser. Nothing is sent anywhere.
