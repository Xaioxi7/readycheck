Pilots and activation codes

Add a pilot, then give them the code. They sign in with company code, Crew ID and this code. Pilots can later make their own recovery code for a new phone.

Tag encryption key

Your company's own key pair. Pilots' phones get only the public half, which locks tag records. The private half opens them: only you and your base station have it.

Read a tag record

Paste the text from a tag (it starts with RC2.) to see exactly what it holds.

You see only what each pilot chose to share: level 1 shows that a check was done, level 2 adds Ready, Caution or Low alertness, level 3 adds reaction time and duty load. ReadyCheck never decides fitness to fly; that stays with the pilot and your fatigue policy.
